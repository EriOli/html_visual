# Visuais personalizados em HTML

Este repositório reúne componentes e dashboards em HTML/CSS para uso em relatórios do Power BI e outras visualizações analíticas. Os arquivos foram criados para servir como base para gráficos, cartões de KPI e tabelas com interações visuais, permitindo maior controle sobre layout e estilo.

## Conteúdo

- [`tabela_com_pagina&exibicao_por_qnt.htm`](./tabela_com_pagina%26exibicao_por_qnt.htm): tabela com paginação, exibição de quantidade por página e layout de ranking com dados tabulares.
- [`tabela_com_busca&grafico_cont_prct.htm`](./tabela_com_busca%26grafico_cont_prct.htm): tabela com busca, filtros e gráfico de comparação percentual para análise detalhada por item ou categoria.
- [`chart_barr_with_tootip tooltip.htm`](./chart_barr_with_tootip%20tooltip.htm): gráfico de barras com tooltip interativo e opções de seleção para comparação por período.
- [`cards_tree_vs_prct_anterior.htm`](./cards_tree_vs_prct_anterior.htm): conjunto de três cartões com valores e variação percentual em relação ao período anterior.
- [`cards_notice_center.htm`](./cards_notice_center.htm): painel com área de destaques/notificações e seleção de período para acompanhamento visual.
- [`cards_four_vs_prct_anterior.htm`](./cards_four_vs_prct_anterior.htm): painel com quatro cartões de KPI, destacando crescimento ou queda frente ao período anterior.
- [`card_meta_with_barr.htm`](./card_meta_with_barr.htm): cartão de meta com barra de progresso, percentual do objetivo alcançado e comparação com a meta estabelecida.
- [`Sales_by_time.htm`](./Sales_by_time.htm): exemplo de gráfico de vendas ao longo do tempo, com comparação entre a semana atual e a anterior. O visual inclui valores de destaque, linhas de tendência, área preenchida e detalhes exibidos ao passar o mouse sobre os dias.
- [`summary_page_quarter.htm`](./summary_page_quarter.htm): página de resumo trimestral por área, com foco no forecast do Q3 2025. Apresenta uma narrativa visual para destacar o impacto de cada área nos resultados.
- [`four_cards_with_hover.htm`](./four_cards_with_hover.htm): painel de forecast com quatro cartões de indicadores. Ao passar o mouse sobre um cartão, ele vira e exibe informações complementares, como variação, confiança e tendências.
- [`card_revenue.htm`](./card_revenue.htm): cartão de KPI de receita que mostra o valor, a variação percentual e a comparação com o mês anterior.

## Como usar

Os arquivos são trechos HTML/CSS, geralmente prontos para serem incorporados em soluções que suportem renderização de HTML no Power BI ou em ambientes web personalizados. A compatibilidade com recursos como CSS, SVG e interações depende do contexto de uso e das políticas de segurança do ambiente.

## Personalização

Os exemplos contêm valores, rótulos, estilos e dados fixos diretamente no código. Para adaptar cada visual ao seu cenário, é possível editar textos, cores, métricas e estruturas do layout. Caso a intenção seja conectar os dados do modelo de forma dinâmica, será necessário integrar o HTML a uma solução que faça essa vinculação.
